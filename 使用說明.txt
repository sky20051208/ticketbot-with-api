搶票機器人使用說明
==========================================

支援拓元（Tixcraft）/ KKTIX / TicketPlus 三大平台。
網頁版 War-Room 介面，可同時操作多個帳號。


【一、系統需求】
------------------------------------------

1. Windows 10 / 11
2. Python 3.10 ~ 3.12（不能裝 3.13）
   下載：https://www.python.org/downloads/
   安裝時務必把最下面的「Add Python to PATH」打勾，
   否則之後 setup.bat 會找不到 Python。
3. Google Chrome（瀏覽器模式才需要；多數人本來就有）


【二、第一次安裝（5~10 分鐘）】
------------------------------------------

1. 把這整個資料夾解壓到任意位置
   （例：D:\ticketbot；路徑不要有中文或空白比較保險）
2. 雙擊 setup.bat
3. 等它跑完——黑窗顯示「Setup complete!」就 OK
4. 之後不用再跑 setup.bat（除非要更新套件）

如果中途出現紅色 [ERROR]，截圖訊息問給你檔案的人。


【三、登入你的帳號（每個帳號做一次）】
------------------------------------------

每個拓元帳號第一次使用前，先建立一份「登入記憶」：

1. 雙擊 create_profile.bat
2. 黑窗會問你帳號名稱——自己取一個好記的英文名
   （例：my_account_1；這只是資料夾名，跟拓元帳號名無關）
3. 它會開一個 Chrome 視窗、自動跳到拓元登入頁
4. 在那個視窗登入你的拓元帳號（用 Google 登入也可以）
5. 登入完成後「關掉那個 Chrome 視窗」，回黑窗按 Enter
6. 有幾個帳號就重複幾次，每次取不同名字

之後 bot 就能靠這個 profile 自動帶你的登入狀態，
不用再手動複製貼上 cookie，cookie 也比較不會中途失效。

★ 一個拓元帳號只能在一個地方用，不要多人共用同一個帳號。
★ 跑 create_profile.bat 時，不要同時用你自己的 Chrome 開著同一個 profile。


【四、每次搶票】
------------------------------------------

1. 雙擊 start.bat
   黑窗開啟、瀏覽器自動跳到 http://127.0.0.1:7860
2. 在網頁上設定（見下方「網頁 GUI 操作」）
3. 開搶前 5 分鐘按 START ALL
4. 結束後關掉黑窗，所有 bot 會一起停


【五、網頁 GUI 操作】
------------------------------------------

▼ 設定要開幾組（多開）

  - 上方 INSTANCES 框輸入數字（例 2 = 兩組同時搶）
  - 按 INIT 建立卡片


▼ 每張卡片要填的東西

  ┌──────────────┬─────────────────────────────────────────┐
  │ 模式選單      │ API模式（拓元，最快）                    │
  │              │ 瀏覽器模式（KKTIX、TicketPlus 必選）     │
  │ PLATFORM     │ TIXCRAFT / KKTIX / TICKETPLUS            │
  │ ACTIVITY SLUG│ 活動代號（活動網址最後一段）             │
  │              │ 例：26_mj116kh_r                         │
  │ START TIME   │ 開賣時間 24 小時制，例：12:00:00         │
  │ QTY          │ 張數                                     │
  │ AREA MODE    │ 選位策略：                               │
  │              │   關鍵字優先 / 由上而下 / 由下而上 / 隨機 │
  │ AREA KEYWORD │ 想要的區或票價關鍵字（例：5800）         │
  │ EXCLUDE (;)  │ 不要的區，分號隔開                       │
  │              │ 例：輪椅;身障;Restricted View            │
  │ DATE         │ 場次日期關鍵字（多場次活動才用）         │
  │ PRESALE CODE │ 會員碼（沒有就空著）                     │
  │ WATCH URL    │ 瀏覽器模式定時開搶要監控的頁面網址       │
  │ TIMER        │ 勾＝定時開搶；不勾＝立刻開搶             │
  │ PROXY POOL   │ 勾＝走 CliProxy 住宅 IP（已幫你設好）   │
  │              │ 不勾＝直接用你家網路 IP                  │
  │ 帳號 PROFILE │ 選你用 create_profile.bat 建好的帳號     │
  │              │ 選了就自動帶登入狀態，COOKIE 欄會鎖起來  │
  │              │ 選「(手貼COOKIE)」才需要自己填 COOKIE    │
  │ COOKIE       │ 只有「帳號 PROFILE = (手貼COOKIE)」時才   │
  │              │ 要填，填法見下方教學                     │
  └──────────────┴─────────────────────────────────────────┘

  欄位改了會自動存檔，不用按存檔鍵。
  ★ 推薦用「帳號 PROFILE」（先跑 create_profile.bat），
    比手貼 cookie 穩，cookie 不會中途失效。
  ★ 新增 profile 後要重整網頁，下拉選單才會出現。

  另外兩個連動規則：
  - AREA MODE 不是「關鍵字優先」時，AREA KEYWORD 會鎖起來
  - 選了帳號 PROFILE 時，COOKIE 欄會鎖起來


▼ 怎麼帶登入狀態（兩種方式）

  【方式 A：帳號 PROFILE（推薦，拓元用）】

  先跑 create_profile.bat 登入過（見【三】），
  之後在卡片的「帳號 PROFILE」下拉選那個帳號即可，
  bot 會自己開 Chrome 抓 cookie，COOKIE 欄不用填。

  【方式 B：手貼 COOKIE】

  KKTIX / TicketPlus 目前只能用這個；拓元想用也可以。
  卡片「帳號 PROFILE」要保持選「(手貼COOKIE)」。

  1. 用 Chrome 打開該網站並「登入」你的帳號
  2. 鍵盤按 F12 打開開發者工具
  3. 上方分頁切到「Console」
  4. 貼上這行按 Enter：

         copy(document.cookie)

  5. cookie 字串就被複製到剪貼簿了
  6. 回到網頁 GUI，貼到 COOKIE 欄位（Ctrl+V）

  ★ COOKIE 等於你的帳號登入狀態，不要外流。


▼ START / PAUSE / STOP / START ALL / STOP ALL

  START      啟動該卡片的 bot
             （瀏覽器模式會自動開一個 Chrome 視窗）
  PAUSE      暫停在當下、不繼續打 server；再按一次繼續
  STOP       直接關掉這張卡片的 bot
  START ALL  一鍵啟動全部卡片
  STOP ALL   一鍵停掉全部卡片


【六、常見問題】
------------------------------------------

Q. 我裝了 Python，但 setup.bat 說找不到。
A. 重跑 Python 安裝程式 → 選 Modify
   → 確認「Add Python to PATH」有打勾，然後 Next 重裝
   → 重啟電腦再跑 setup.bat。

Q. setup.bat 裝套件裝到一半失敗。
A. 多半是網路問題，重跑一次。
   如果固定卡在某個套件，截圖訊息問。

Q. 瀏覽器模式按 START 但沒開 Chrome。
A. 確認電腦有裝 Google Chrome（Edge 不算）。

Q. 拓元搶到一半 cookie 失效（log 出現 Cookie 失效）。
A. 重新登入拓元 → Console 跑 copy(document.cookie)
   → 貼新的 cookie 進 GUI → 重 START。

Q. 驗證碼一直辨識錯。
A. ddddocr 不是 100%，難的字會錯。
   程式設定 5 次內會自動換一張重試，平均都搶得到。

Q. PROXY POOL 是什麼？要勾嗎？
A. 透過給你檔案的人付費的 CliProxy 走台灣住宅 IP，
   每個 instance 會拿到不同出口 IP，比較不會被風控擋。
   設定已經填好，要勾就勾、不勾就走你家網路。
   ★ 不要把這個 zip 轉發給其他人，proxy 帳密在 config.py 裡。

Q. 黑窗一閃就關掉。
A. 不要直接點 .py，要點 setup.bat / start.bat。
   如果是 .bat 也閃退，從黑窗手動跑（cmd cd 到資料夾，輸入 setup.bat），
   就能看到完整錯誤訊息。

Q. setup.bat 開起來只看到「Python 3.10.11」+「按任意鍵」就退出。
A. 表示 cmd 把 .bat 換行格式吃壞了。
   解法：用滑鼠右鍵 setup.bat → 內容 → 確認檔案沒被防毒清理或編輯器
   存成 LF-only。最快做法：重新解壓一次原始 zip 就好。

Q. 網頁打不開（127.0.0.1:7860 拒絕連線）。
A. 確認 start.bat 黑窗還開著、有看到 "Uvicorn running" 訊息。
   防火牆第一次跳出來時要按「允許」。


【七、要更新（如果之後拿到新版）】
------------------------------------------

1. 解壓新版到「新資料夾」（不要蓋舊的）
2. 把舊資料夾裡的 profiles\ 複製到新資料夾
   （這樣保留你的卡片設定）
3. 對新資料夾跑一次 setup.bat（重裝套件）
4. 之後跑新版的 start.bat
